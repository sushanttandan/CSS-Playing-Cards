# 🃏 CSS Playing Cards

A playing card design created using **pure HTML and CSS**, without JavaScript.

## ✨ Features

- Custom playing card design
- CSS-based styling and positioning
- Clean and simple layout
- No JavaScript required

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Files

- `index.html` — Contains the HTML structure.
- `style.css` — Contains the CSS styling.

## 🎯 Purpose

This project is part of my journey into frontend development. It explores the creative possibilities of CSS and demonstrates how visually appealing designs can be created without JavaScript.
